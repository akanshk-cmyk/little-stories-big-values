# Static story-character selection pictures

Veyd: `veyd.png` is the exact static illustration supplied by the user from
`the user-supplied veyd.png attachment`. It is bundled as the default selection-card
portrait, with the existing square card and contain sizing. It does not depend on
browser storage or an appearance upload. A failed custom portrait falls back to
this bundled image. This is selection artwork, not approval of book scene assets.

Krishna, Ganesha and Hanuman pictures were downloaded from the static reference links supplied by the user and visually checked against the user's example. They are selection-card assets only. No image-generation API was used and no image-generation feature was re-enabled. Keeping local copies avoids runtime requests to external picture services.

These assets do not establish source eligibility, rights clearance, human cultural approval or accepted character references for a generated book. This prototype is local; production asset eligibility remains to be verified.

Reference link labels supplied by the user: Krishna (Pikbest link label), Ganesha (AIClips link label), Hanuman (Medium story link label). Labels are provenance notes supplied in the conversation, not verified ownership claims.

Rama: `rama.png` is the exact user-supplied illustration copied from
`the user-supplied rama.png attachment`. Both Discover and Story Studio load this
bundled static asset by default, using the existing card dimensions. No browser
upload is required. The optional Choose/Paste controls still support a personal
browser override. This selection picture does not establish approval for book
scene assets, cultural evidence or usage rights beyond the supplied app artwork.
